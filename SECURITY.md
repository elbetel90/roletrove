# Security Policy

## supported versions

This project is pre-1.0. Security fixes land on `main`.

## reporting a vulnerability

Do not open a public issue for security reports.

Contact the repository owner on GitHub ([@elbetel90](https://github.com/elbetel90)). Include enough detail to reproduce the issue (affected path, expected vs actual behavior, and impact).

You should hear back within 7 days. Please give us a reasonable window to patch before any public disclosure.

After the repository is public, enable [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) in **Settings → Code security** so reporters can use GitHub's private advisory form.

## non-security issues

Bugs, crawl problems, and feature requests belong in [GitHub issues](https://github.com/elbetel90/roletrove/issues).
