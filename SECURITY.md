# Security Policy

## supported versions

This project is pre-1.0. Security fixes land on `main`.

## reporting a vulnerability

Do not open a public issue for security reports.

Please use [GitHub private security advisories](https://github.com/elbetel90/roletrove/security/advisories/new).
Include enough detail to reproduce the issue (affected path, expected vs actual behavior, and impact).

You should hear back within 7 days. Please give us a reasonable window to patch before any public disclosure.

## non-security issues

Bugs, crawl problems, and feature requests belong in [GitHub issues](https://github.com/elbetel90/roletrove/issues).
